# 🤖 Divar Web Automation with Playwright

## 📌 معرفی پروژه

این پروژه یک سیستم اتوماسیون مرورگر (Browser Automation) است که با استفاده از زبان برنامه‌نویسی Python و کتابخانه Playwright توسعه داده شده است.

در این پروژه مرورگر Chrome به‌صورت خودکار اجرا شده و عملیات مختلفی در وب‌سایت دیوار (Divar) انجام می‌شود.

هدف اصلی پروژه، خودکارسازی تعامل با صفحات وب، شناسایی المان‌های صفحه، کلیک روی دکمه‌ها و تکمیل فرم‌ها بدون دخالت مستقیم کاربر است.

## ✨ امکانات پروژه

- 🌐 اجرای خودکار مرورگر Chrome
- 🤖 اتصال به وب‌سایت دیوار (Divar)
- 🖱️ کلیک خودکار روی لینک‌ها و دکمه‌ها
- 🔍 شناسایی المان‌های صفحه با استفاده از Role و Name
- 📝 تکمیل خودکار فیلدهای ورودی
- 📱 وارد کردن شماره تلفن در فرم مربوطه
- ⚡ انجام مراحل مختلف وب‌سایت به‌صورت خودکار
- 🖥️ امکان مشاهده عملکرد مرورگر هنگام اجرا

## 🛠️ تکنولوژی‌های استفاده‌شده

- Python
- Playwright
- Chromium
- Google Chrome
- Browser Automation

## ⚙️ پیش‌نیازها

ابتدا Python را نصب کنید.

سپس کتابخانه Playwright را نصب نمایید:

```bash
pip install playwright
```

برای نصب مرورگرهای موردنیاز Playwright:

```bash
playwright install
```

## 🚀 نحوه نصب و اجرا

**1. دریافت پروژه از GitHub**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. ورود به پوشه پروژه**

```bash
cd PLAYWRIGHT_PROJECT
```

**3. نصب وابستگی‌ها**

```bash
pip install -r requirements.txt
```

**4. نصب مرورگر Playwright**

```bash
playwright install chromium
```

**5. اجرای برنامه**

```bash
python src/app.py
```

## 🧠 نحوه عملکرد پروژه

1. با استفاده از Playwright مرورگر Chrome اجرا می‌شود.
2. یک صفحه جدید در مرورگر ایجاد می‌شود.
3. برنامه وارد وب‌سایت دیوار می‌شود.
4. لینک‌ها و دکمه‌های موردنظر با استفاده از Locator شناسایی می‌شوند.
5. عملیات کلیک به‌صورت خودکار انجام می‌شود.
6. اطلاعات موردنیاز در فیلدهای ورودی ثبت می‌شوند.
7. با کلیک روی دکمه بعدی، فرآیند به مرحله بعد منتقل می‌شود.
